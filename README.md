# AI Engineering Academy

Plataforma para formar AI Engineers Senior mediante un roadmap práctico basado en proyectos reales, construido con Claude Code, el Model Context Protocol (MCP) y las mejores prácticas de ingeniería de software.

## Qué es esto

AI Engineering Academy no es un curso de slides: es un camino de aprendizaje donde cada concepto se valida construyendo software real — con historias de usuario, diseño revisado, pruebas automatizadas y documentación viva, tal como se trabajaría en un equipo de ingeniería serio.

📖 **¿Nuevo en el proyecto?** Empieza por [PROJECT_BIBLE.md](./PROJECT_BIBLE.md) — la fuente única de verdad (Single Source of Truth) que consolida toda la estrategia, el producto y la arquitectura en un solo documento.

Consulta [VISION.md](./VISION.md) para la misión, el público objetivo y la propuesta de valor completa.

## Público objetivo

- Desarrolladores backend/fullstack que quieren especializarse en IA generativa.
- Data Scientists / ML Engineers que buscan llevar sistemas a producción con buenas prácticas.
- Estudiantes avanzados que buscan un portafolio de proyectos reales, no ejercicios de juguete.

## Estado actual

🚧 **Fase de fundación.** El proyecto se encuentra en la etapa de definición de visión, alcance y roadmap. Aún no existe implementación de plataforma ni infraestructura.

Consulta [ROADMAP.md](./ROADMAP.md) para el plan de alto nivel por fases.

## Cómo trabajamos

Este repositorio sigue un conjunto de reglas de ingeniería explícitas (ver [CLAUDE.md](./CLAUDE.md)):

- No se escribe código sin historia de usuario y diseño aprobado.
- README, CHANGELOG, BACKLOG y documentación técnica se mantienen sincronizados en cada cambio.
- Las decisiones arquitectónicas relevantes se registran como ADR.
- Toda funcionalidad nueva o modificada requiere pruebas automatizadas.
- Los cambios son pequeños e incrementales: un sprint se completa antes de iniciar el siguiente.
- El contenido educativo sobre Claude y MCP se basa en la documentación oficial de Anthropic.
